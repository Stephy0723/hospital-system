# Stelia Salud

Demo independiente de exhibición de **Stelia**, por **Stephanie López Frías**.

## Ejecutar

Abre `index.html` o sirve esta carpeta con `python -m http.server 8080`.
No requiere dependencias ni backend. Se puede alojar en GitHub Pages.

## Demo navegable

https://steliant-soft-portfolio.steliantsoft.chatgpt.site/demos/stelia-salud/

## Base revisada

`Stephy0723/hospital-system`. Esta muestra reconstruye una selección de flujos en HTML/CSS/JS;
no es el código completo ni una sustitución del proyecto original.

## Incluye

- Búsqueda por especialidad
- Selección de fecha y hora
- Registro y cancelación de citas locales

## Limitaciones

Los profesionales y horarios son ficticios. No se solicitan datos médicos ni se reservan consultas reales.
Todos los registros son ejemplos locales. No introduzcas datos personales o secretos.
El video de YouTube está pendiente; no se suministró ningún enlace.

## Publicación independiente

Esta carpeta puede subirse a un repositorio nuevo llamado `stelia-salud`.
Para GitHub Pages, publica desde la raíz de la rama que contenga estos cuatro archivos.
El portafolio y las demos están separados del panel administrativo anterior.
